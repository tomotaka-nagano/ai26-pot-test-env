# 話題沸騰ポット（GOMA-1015型）製品テストシナリオ

## 共通の初期状態

すべてのシナリオは、特に記載がない限り以下の状態から開始する。

| 項目           | 初期値                 |
| -------------- | ---------------------- |
| 水量           | 0 ml                  |
| 水温           | 外気温（25℃）         |
| 蓋             | 開                     |
| ポット状態     | IDLE                   |
| 保温モード     | 高温（98℃）           |
| ロック状態     | ロック中               |
| タイマ         | 未設定（0分）          |
| ヒータ         | OFF                    |
| ヒータ用電源   | ON                     |
| ポンプ         | OFF                    |
| エラー         | なし                   |

## 事前条件成立のための操作手順

各シナリオで初期状態以外の状態から開始する必要がある場合、以下の操作手順で前提状態を構築する。

### PRE-A: 沸騰完了・高温保温状態

1. 水を 600 ml 注ぐ
2. 蓋を閉じる → 自動で沸騰開始
3. 沸騰完了（100℃到達後 3 分経過）まで待つ
4. 状態が「保温（高温 98℃）」であることを確認

### PRE-B: 任意の保温モードで保温中

1. PRE-A を実施
2. 保温設定ボタンを必要回数押下し、目的のモードに切り替える
   - 節約: 1 回（高温→節約）
   - ミルク: 2 回（高温→節約→ミルク）

### PRE-C: ロック解除状態

1. 解除ボタンを押下する
2. ロックランプが消灯していることを確認

### PRE-D: 給湯可能状態

1. PRE-A を実施
2. PRE-C を実施

## 1. 蓋の開閉と沸騰開始

### S-1.1: 温度制御可能水位で蓋を閉じる → 沸騰開始

**操作:**

1. 水を 600 ml 注ぐ
2. 蓋を閉じる

**期待結果:**

- 状態が「沸騰」に遷移する
- 沸騰ランプが点灯する
- 保温ランプが消灯する
- ヒータが ON になる

### S-1.2: 水量不足で蓋を閉じる → 沸騰開始しない

**操作:**

1. 水を注がない（0 ml）
2. 蓋を閉じる

**期待結果:**

- 状態が「IDLE」のまま変化しない
- 沸騰ランプが消灯のまま
- ヒータが OFF のまま

### S-1.3: 満水状態で蓋を閉じる → 沸騰開始しない

**操作:**

1. 水を満水センサが ON になる量（1000 ml 以上）注ぐ
2. 蓋を閉じる

**期待結果:**

- 状態が「IDLE」のまま変化しない
- 沸騰ランプが消灯のまま
- ヒータが OFF のまま

### S-1.4: 沸騰中に蓋を開ける → ヒータ停止

**前提:** PRE-A の手順 1〜2 を実施し、沸騰中の状態とする。

**操作:**

1. 蓋を開ける

**期待結果:**

- ヒータが OFF になる
- 沸騰ランプが消灯する
- 保温ランプが消灯する
- 状態が「IDLE」に遷移する

### S-1.5: 保温中に蓋を開ける → ヒータ停止

**前提:** PRE-A を実施（高温保温中）。

**操作:**

1. 蓋を開ける

**期待結果:**

- ヒータが OFF になる
- 状態が「IDLE」に遷移する

### S-1.6: 蓋を開けてから再度閉じる → 沸騰再開

**前提:** S-1.4 の操作後の状態（IDLE、蓋が開いている、水量は制御可能水位）。

**操作:**

1. 蓋を閉じる

**期待結果:**

- 状態が「沸騰」に遷移する
- ヒータが ON になる

## 2. 沸騰動作

### S-2.1: 沸騰 → 100℃到達後 3 分間加熱 → 保温に移行

**操作:**

1. 水を 600 ml 注ぐ
2. 蓋を閉じる
3. 100℃に到達するまで待つ
4. さらに 3 分間待つ

**期待結果:**

- 100℃到達後もヒータが ON（カルキ抜き加熱）
- 3 分経過後に状態が「保温」に遷移する
- 沸騰ランプが消灯する
- 保温ランプが点灯する
- ブザーが 3 回鳴る（沸騰完了通知）

### S-2.2: 沸騰中に沸騰ボタンを押す → 沸騰中止、保温に移行

**前提:** 水 600 ml を注いで蓋を閉じ、沸騰中の状態とする。

**操作:**

1. 沸騰ボタンを押下する

**期待結果:**

- 状態が「保温」に遷移する
- ブザーが 1 回鳴る（ボタン操作応答）
- 沸騰ランプが消灯する
- 保温ランプが点灯する

### S-2.3: 保温中に沸騰ボタンを押す → 再沸騰

**前提:** PRE-A を実施（保温中）。

**操作:**

1. 沸騰ボタンを押下する

**期待結果:**

- 状態が「沸騰」に遷移する
- ブザーが 1 回鳴る
- 沸騰ランプが点灯する
- 保温ランプが消灯する
- ヒータが ON になる

### S-2.4: 蓋が開いている状態で沸騰ボタン → 無効

**操作:**

1. 水を 600 ml 注ぐ（蓋は開いたまま）
2. 沸騰ボタンを押下する

**期待結果:**

- 状態が変化しない
- ブザーが鳴らない
- ヒータが OFF のまま

### S-2.5: 温度制御不可能水位で沸騰ボタン → 無効

**操作:**

1. 蓋を閉じる（水量 0 ml）
2. 沸騰ボタンを押下する

**期待結果:**

- 状態が変化しない
- ブザーが鳴らない
- ヒータが OFF のまま

## 3. 保温モード

### S-3.1: 高温モード（98℃）での保温維持

**前提:** PRE-A を実施。

**期待結果:**

- 水温が約 98℃近辺で維持される
- 保温モード表示が「高温」を示す

### S-3.2: 保温設定ボタンで高温→節約→ミルク→高温と切り替え

**前提:** PRE-A を実施。

**操作:**

1. 保温設定ボタンを 1 回押下する

**期待結果:**

- 保温モードが「節約（90℃）」に変更される
- ブザーが 1 回鳴る
- モード表示が「節約」を示す

**操作（続き）:**

2. 保温設定ボタンをさらに 1 回押下する

**期待結果:**

- 保温モードが「ミルク（60℃）」に変更される

**操作（続き）:**

3. 保温設定ボタンをさらに 1 回押下する

**期待結果:**

- 保温モードが「高温（98℃）」に戻る

### S-3.3: 節約モード（90℃）での保温維持

**前提:** PRE-B（節約）を実施。

**期待結果（時間経過後）:**

- 水温が約 90℃近辺で維持される

### S-3.4: ミルクモード（60℃）での保温維持

**前提:** PRE-B（ミルク）を実施。

**期待結果（時間経過後）:**

- 水温が約 60℃近辺で維持される

### S-3.5: 保温モード設定時に 100℃でない場合 → 一度沸騰してから冷却

**操作:**

1. 水を 600 ml 注ぐ
2. 蓋を閉じる → 沸騰開始
3. 沸騰完了を待つ（保温に移行）
4. 保温設定ボタンを 2 回押下してミルクモード（60℃）にする

**期待結果:**

- 水温が 100℃付近から自然冷却で 60℃へ向かう
- 60℃近辺に達するとヒータ制御で維持される

### S-3.6: IDLE からの保温モード変更 → 沸騰開始後に適用

**操作:**

1. 保温設定ボタンを 1 回押下して節約モードにする
2. 水を 600 ml 注ぐ
3. 蓋を閉じる → 沸騰開始
4. 沸騰完了を待つ

**期待結果:**

- 沸騰完了後、節約モード（90℃）で保温が開始される

## 4. 給湯（ロックと給湯ボタン）

### S-4.1: ロック中に給湯ボタンを押す → 給湯しない

**前提:** PRE-A を実施（ロック状態で保温中）。

**操作:**

1. 給湯ボタンを押下する

**期待結果:**

- ポンプが OFF のまま
- 水が排出されない
- ブザーが 1 回鳴る

### S-4.2: ロック解除して給湯 → 水が排出される

**前提:** PRE-D を実施。

**操作:**

1. 給湯ボタンを押し続ける（5 秒間）
2. 給湯ボタンを離す

**期待結果（押し続けている間）:**

- ポンプが ON になる
- 水量が減少する
- 水が水路を通って排出される

**期待結果（離した後）:**

- ポンプが OFF になる
- 給湯が停止する

### S-4.3: 解除ボタンでロック/解除を切り替え

**操作:**

1. 解除ボタンを押下する

**期待結果:**

- ロック解除状態（ロックランプ消灯）

**操作（続き）:**

2. 解除ボタンを再度押下する

**期待結果:**

- ロック状態に戻る（ロックランプ点灯）

### S-4.4: 給湯中にロックボタンを押す → ロックできない

**前提:** PRE-D を実施。

**操作:**

1. 給湯ボタンを押し続ける（給湯中にする）
2. 給湯中に解除ボタンを押下する

**期待結果:**

- ロック解除状態のまま変化しない
- 給湯が継続される

### S-4.5: 水量が 0 のときに給湯ボタンを押す → 空振り

**前提:** PRE-C を実施（ロック解除、水量 0）。

**操作:**

1. 給湯ボタンを押下する

**期待結果:**

- ポンプ動作するが水は排出されない
- 水量は 0 のまま

## 10. エラー検知 — 高温エラー

### S-10.1: 水温 110℃超過 → 高温エラー

**前提:** 沸騰中の状態。

**故障操作:**

1. ヒータが停止不能になる故障をシミュレートする（ヒータが OFF にならない）
2. 水温が 110℃を超過するまで待つ

**期待結果:**

- ヒータ用電源が OFF になる
- ブザーが 30 秒間鳴動する
- 状態が「エラー」に遷移する
- 沸騰ランプ・保温ランプが消灯する

### S-10.2: 高温エラー後のブザー鳴動時間

**前提:** S-10.1 の操作でエラー状態になった直後。

**操作:**

1. 30 秒間待つ

**期待結果:**

- ブザーが 30 秒間鳴り続ける
- 30 秒経過後にブザーが停止する
- エラー状態は維持される（自動復帰しない）

## 11. エラー検知 — 温度上がらずエラー

### S-11.1: ヒータ制御中に温度が低下 → 温度上がらずエラー

**前提:** 保温中（高温 98℃）の状態。

**故障操作:**

1. ヒータが実質動作しない故障をシミュレートする
2. 水温が目標温度より 5℃以上低下するまで待つ（例: 92℃以下）
3. さらに 1 分以内に前回検出温度より今回検出温度が低くなったことを確認する

**期待結果:**

- ヒータ用電源が OFF になる
- ブザーが 30 秒間鳴動する
- 状態が「エラー」に遷移する

### S-11.2: 目標温度より 5℃以上低いが温度上昇中 → エラーにならない

**前提:** 保温中（高温 98℃）の状態。

**故障操作:**

1. 一時的にヒータ出力を低下させ、水温を目標温度より 5℃以上下げる
2. その後ヒータを復旧させ、温度が上昇傾向にある状態で 1 分の検出周期を迎える

**期待結果:**

- 今回検出温度 > 前回検出温度のため、エラーとならない
- 正常動作が継続する

### S-11.3: 温度検出周期（1 分）の確認

**前提:** 保温中の状態。

**故障操作:**

1. ヒータの故障をシミュレートする
2. 50 秒経過時点の状態を確認する

**期待結果:**

- 50 秒時点ではまだエラー検知が発生しない（検出周期到達前）

**操作（続き）:**

3. さらに 10 秒以上待つ（計 60 秒以上経過）

**期待結果:**

- 1 分の検出周期到達後にエラー条件判定が行われる

## 12. 複合シナリオ

### S-12.1: 沸騰完了 → 保温モード変更 → 再沸騰 → 保温

**操作:**

1. 水を 600 ml 注ぎ、蓋を閉じる
2. 沸騰完了を待つ（高温保温に移行）
3. 保温設定ボタンを 2 回押下（ミルクモードに変更）
4. 水温が 60℃近辺で安定するまで待つ
5. 沸騰ボタンを押下する
6. 再沸騰完了を待つ

**期待結果:**

- 手順 3 後: ミルクモードに切り替わる
- 手順 4 後: 水温が約 60℃で維持される
- 手順 5 後: 再度沸騰状態に遷移する
- 手順 6 後: 保温に戻り、ミルクモード（60℃）で保温が継続される

### S-12.2: 給湯による水位低下 → 温度制御不可 → 水追加 → 復帰

**前提:** PRE-D を実施（水 600 ml、保温中、ロック解除）。

**操作:**

1. 給湯ボタンを長時間押し続け、水量を第 1 水位センサ以下まで減らす
2. 給湯ボタンを離す
3. 蓋を閉じる

**期待結果（手順 2 後）:**

- 温度制御が不可能（水位センサ全 OFF）
- ヒータが OFF になる
- 沸騰ランプ・保温ランプが消灯する

**操作（続き）:**

4. 蓋を開ける
5. 水を 600 ml 注ぐ
6. 蓋を閉じる

**期待結果:**

- 温度制御可能水位に戻り、沸騰が開始される

### S-12.3: タイマとボタン操作の並行動作

**前提:** PRE-A を実施。

**操作:**

1. タイマボタンを 3 回押下（3 分タイマ設定）
2. 保温設定ボタンを 1 回押下（節約モードに変更）
3. 3 分間待つ

**期待結果:**

- タイマが作動中も保温が正常に制御される
- 3 分後にタイマがタイムアウトし、ブザーが 3 回鳴る
- 保温はそのまま動作を継続する

### S-12.4: 沸騰中に蓋を開閉して再沸騰

**操作:**

1. 水を 600 ml 注ぎ、蓋を閉じる（沸騰開始）
2. 50℃付近に到達した段階で蓋を開ける
3. しばらく待つ（水温が若干冷却される）
4. 蓋を再度閉じる

**期待結果:**

- 手順 2: 沸騰が中断され IDLE に遷移
- 手順 4: 沸騰が再開始される（100℃到達後 3 分間のカウントはリセット）
- 最終的に沸騰完了し保温に移行する

### S-12.5: エラー発生後の操作はすべて無効

**前提:** S-10.1 を実施（エラー状態）

**操作:**

1. 沸騰ボタンを押下する
2. 保温設定ボタンを押下する
3. 解除ボタンを押下する
4. 給湯ボタンを押下する

**期待結果:**

- いずれの操作も状態を変化させない
- エラー状態が維持される
- ヒータ用電源は OFF のまま

### S-12.6: 保温中に水を追加 → 再沸騰

**前提:** PRE-A を実施（高温保温中、98℃近辺）。

**操作:**

1. 蓋を開ける（IDLE に遷移）
2. 水を 300 ml 追加する（水温が下がる: 加重平均で混合）
3. 蓋を閉じる

**期待結果:**

- 水温が外気温とポット内水温の加重平均に下がる
- 温度制御可能であれば沸騰が再開される
- 沸騰完了後に保温に移行する
